# Scribble

Notes, lists and sketches, kept as real files.

## What it does

- Notes are plain Markdown (`.md`) and text (`.txt`) files in folders. Use Scribble's private folder, or choose any folder, such as an Obsidian vault, in Settings › Notes folder.
- Markdown preview with headings, bold, italic, quotes, code, highlights, and tappable checklists. `[[Wiki links]]` jump between notes, and each note shows what links to it.
- Checklists continue as you press Enter. Pin notes, give them paper colours, search everything, find and replace, and undo/redo.
- **Sketches**: pen, line, box and oval tools, colours, sizes, an eraser, and plain, lined or grid paper. Saved as PNG files.
- Import and export text files, a home-screen notepad widget, and a recycle bin that keeps notes for 30 days.
